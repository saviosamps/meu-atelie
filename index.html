Backup e transferência

Exporte seus cadastros para um arquivo e guarde-o em um local privado. Para transferir os dados para outro dispositivo, importe esse arquivo nele.

Os dados ficam neste navegador. Não existe sincronização automática entre computador e tablet. O repositório público contém o código do aplicativo, não deve conter seus arquivos de backup.

Importar um backup substitui os cadastros atuais deste navegador. Exporte os dados atuais antes de importar.
